# Betheme FIX4U Design (preview copy)

Child theme of the active **Betheme** theme. Designed for review only.

## Status
- Installed on the site as **Betheme FIX4U Design**
- **Not activated** — live site stays on Betheme
- Review with Live Preview (see below)

## How to preview (no activation)
1. Log in at https://fix4u.co.nz/admin
2. Go to **Appearance → Themes**
3. Find **Betheme FIX4U Design**
4. Click **Live Preview** (or Customize)
5. Check the new home design, then close preview — site visitors still see Betheme

## Notes
- Parent theme remains `betheme` (required)
- File Manager Advanced was installed to attempt a full folder copy, then **deactivated** (not deleted). Ask before deleting that plugin.
