# Repair | Shop site switcher

Canonical handoff for matching the **entire shop chrome** to the main site:

→ **`HANDOFF-shop-match-main-site.md`**

Switcher-only files:

- `site-switcher.css` — main-site (`.bt-a`) rules
- `site-switcher.repair.html` — main site markup (Repair active)
- `site-switcher.shop.html` — shop markup (Shop active)
- `site-switcher-shop.css` — shop-ready CSS (no `.bt-a` dependency)

Live reference: https://fix4u.co.nz/ (top strip)
