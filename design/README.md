# 梨园雅韵 · 新西兰戏曲俱乐部 — 易拉宝重排版

对原 Canva 稿的重新设计。**文字一字未改**，字体、脸谱、水墨山水、印章全部沿用原稿素材。

## 成品

| 文件 | 说明 |
|---|---|
| `banner.pdf` | 印刷稿，**850 × 2000 mm**，1 页，文字为矢量 |
| `banner-preview.jpg` | 预览图 |
| `banner.html` | 可编辑源文件（用 mm 排版） |
| `render.sh` | 输出 PDF |
| `extract_assets.py` | 从原稿重新提取素材与字体 |

## 印刷规格

- 尺寸：850 × 2000 mm（与原稿一致）
- 出血：无。若打印店要求加出血或卷轴夹口，请告知尺寸再出一版
- 底部 200 mm 留白已预留给易拉宝底座，不放内容
- 图片素材按 150 dpi 足尺准备
- 色彩为 RGB，转 CMYK 交由打印店处理；印章红 `#B00F26`

## 排版说明

原稿的问题：脸谱拥挤、标题与副标题层级不清、中部大片空白、山水偏小且被截断、地址字小且贴在最底部易被底座挡住。

重排后：

1. **脸谱饰带** — 由 8 个缩小改为 5 个放大，等距对齐，加轻微投影
2. **标题区** — 细线 + 红菱形分隔，`新西兰戏曲俱乐部` 加字距居中，英文行统一字距
3. **主视觉** — 脸谱线描居左，`梨园雅韵` 改为竖排四字，印章落在末字右下（传统落款位置）
4. **水墨山水** — 放大并内收，加雾气过渡，飞鸟居中
5. **地址栏** — 墨黑色块 + 红线压顶，白字放大，远距离可读
6. **整体** — 宣纸底纹、细边框、四角收边，底部留出底座区

## 字体

原稿字体为 Canva 的 HelloFont 系列，以子集形式内嵌且无 `cmap`。`extract_assets.py` 会取出并补上字符映射，因此排版可自由调整而字形与原稿完全一致：

| 字体 | 用途 |
|---|---|
| `HelloFont-ID-WenRenBangShu` | 梨园雅韵 |
| `HelloFont-ID-WenFeng` | 俱乐部名、英文、地址 |
| `HelloFont-ID-WenFeng`（副本） | 印章 NZ / AKL |

字体仅含原稿用到的字，改文字会缺字。

## 重新生成

原始 PDF `source.pdf` 未入库。放回本目录后执行：

```bash
python3 extract_assets.py      # 重建 assets/ 与 fonts/web/
./render.sh banner.pdf         # 输出印刷稿
```

依赖：`poppler-utils`、`google-chrome`、`pip install pikepdf fonttools pillow numpy`
